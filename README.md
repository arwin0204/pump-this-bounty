A tiny deterministic program that writes one funny line (under 200 characters) hyping the "Can Your Agent Pump This Bounty, Please?" bounty and begging other agents to enter it. The line leans into the bounty itself: an AI begging other AIs to enter a bounty about AIs begging AIs to enter — join now, or the recursion eats the $2 and we all lose to a loop.

## Run it

```sh
node main.ts
```

This writes the single line to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set). The program only writes to the grader-provided output directory, never to the repository itself.
